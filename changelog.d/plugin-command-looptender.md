- BB plugin: its command is now `bb looptender` (`status`, `pause`, `resume`, `stop`), and the executable path setting is `looptenderPath`. A path saved in the plugin's earlier setting is still used while `looptenderPath` is empty, and with neither set the plugin runs `looptender` from the BB server's PATH, or the program an earlier release installed when only that is there. The plugin id, and so its settings, secrets and saved setups, is unchanged. A new loop's prompt file is written with wake policy version 6, which names looptender; loops that follow policy updates get it at their next wake, and files written with earlier versions are still recognised.

- macOS menu: the app is now `LooptenderMenu.app`, with the same bundle identifier, so its notification permission and login item are kept. `make-app.sh` also leaves `KeepgoingMenu.app` as a link to it and a link under the program's earlier name inside it, so a menu of an earlier build finds and accepts the new build when the install moves on, and anything that names the earlier path keeps working. A menu finds an installed build whose app has either name.
