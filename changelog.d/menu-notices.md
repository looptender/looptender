- The macOS menu notifies from the same list of events the panel reads (`panel list --json` `notices`): an agent's question or a loop needing you, a usage limit, a supervisor that stopped answering are pushed by default; a failed lane, a hold, an install, a low disk and a reached deadline or send limit are listed but quiet, and each kind can be switched in **Notify me when…**. Each event is posted once (the first read is a baseline, so starting the menu does not replay what was already open), many that begin together are one notification ("5 loops stopped: usage limit until Fri 04:00."), clicking one opens the loop in the panel, and a **Recent** section lists the last ten with their age. The icon's count is still the loops that need you. With this list the older overdue-check notification is not posted a second time.
