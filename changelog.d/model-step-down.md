- `looptender model-step -c CONFIG --models STRONGEST,NEXT` (the owner's to set) opts a loop into stepping its own BB conversation down to the next model on the same account when only one model's weekly window is blocked (BB's `seven_day_<model>`), retrying the failed turn by reference, and back once that window resets if the conversation is still on the weaker model. A failed change spends no send and waits for the reset. A `model_step` notice and one line in the agent's next message say what changed. The setting is a record in the state directory, not a configuration key. It never acts on lanes, routes or accounts.
