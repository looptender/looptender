- `looptender model-step -c CONFIG --models STRONGEST,NEXT` opts a loop into stepping its own BB conversation down to the next model on the same account when only one model's weekly window is blocked (BB's `seven_day_<model>`), retrying the failed turn by reference with no text sent, and back to the stronger model at the first check between turns after that window resets. The setting is a record in the state directory, not a configuration key. It never acts on lanes, routes or accounts.
