- `looptender usage-watch -c CONFIG --account ID` turns on a warning before the weekly window runs out. It reads the subscription quota of the accounts catalog entry a loop's conversation runs on (no model request) at most every `--every`. When, at the weekly window's rate so far (from 12 hours into the window), it would run out before it resets, `status` and the panel say "At this rate the weekly window is used up in about N h", and when that is within `--warn-within` the agent is woken once per window with a `[keepgoing:usage-burn …]` notice. It never acts on lanes or routes. The setting and the reading are their own records in the state directory, not configuration keys, so older builds load the configuration as before.
