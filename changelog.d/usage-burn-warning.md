- Opt-in `loop.usage_watch` reads the subscription quota of the accounts catalog entry a loop's conversation runs on (no model request), at most every `every`. When, at the weekly window's rate so far, it would run out before it resets, `status` and the panel say "At this rate the weekly window is used up in about N h", and when that is within `warn_within` the agent is woken once per window with a `[keepgoing:usage-burn …]` notice. It never acts on lanes or routes. The reading is its own record, `usage-watch.json`, so no state format changes.
