- `panel list --json` no longer carries account catalog IDs. Each account in `accountQuotas` is named by a handle, which is a keyed digest of the catalog ID under the catalog's own salt. The handle has the same shape, so the macOS menu still accepts it, and `panel --account` accepts it as well as a catalog ID. The panel page and `panel list` now say that a no-progress flag on a held loop was "recorded before the hold" and "is not current", in the words `status` already used and from the same function.
