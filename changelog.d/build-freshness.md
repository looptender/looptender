- The panel and the macOS menu now say how fresh each supervisor's build is, in the same words (one function in Go words them, and `panel list --json` and the dock report carry them): an up-to-date supervisor shows just its version; one that switched builds within the last 24 hours shows `Updated 2 h ago` with `Installed <date time> · was <old> · now <new>`; one that follows installs but has not switched shows `Update pending · switches at next check`; one that does not follow installs shows `Older build · restart the supervisor to update` with the command a person would run (`keepgoing daemon-shutdown -c CONFIG`, which keeps holds and controls). The Overview and the menu start with one line, `Build X installed <when> · N supervisors on it · M older`. Nothing restarts, resumes or re-enables a supervisor. `freshness` is an additive field on each dock loop, on the dock report, and in `panel list --json` (per loop and once); older menu and plugin builds ignore it, and a loop whose daemon reports no build says nothing.
