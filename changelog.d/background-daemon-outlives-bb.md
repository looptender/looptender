- `start --background` from a BB thread now hands the daemon to launchd (`launchctl submit`) on macOS or the user's systemd (`systemd-run --user`) on Linux as a one-off job, so quitting or restarting BB no longer ends it. The job removes itself when the daemon ends. Without a service manager, it starts as before with a warning and the advice to run `looptender service install`. Windows is unchanged and says so. The daemon's `stopped` record now names the signal that ended it, and SIGHUP ends it cleanly.
