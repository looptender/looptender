- `start --background` from a BB thread now hands the daemon to launchd's per-user background domain (`launchctl bootstrap user/<uid>`, with a Background-session property list) on macOS or the user's systemd (`systemd-run --user`) on Linux as a one-off job, so quitting or restarting BB no longer ends it. The job removes itself when the daemon ends. Surviving a BB restart rests on the launch design and stand-in tests; surviving a logout is not verified. Without a service manager, it starts as before with a warning and the advice to run `looptender service install`. Windows is unchanged and says so. The daemon's `stopped` record now names the signal that ended it, and SIGHUP ends it cleanly.
