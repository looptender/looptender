- BB plugin card: a pause or stop asked for from a thread's card now reaches only a loop that thread belongs to (its primary or its current target), checked on the server from the loop's own status, not only offered by the page. Pausing a loop whose target is another thread asks first and names the loop and the thread it supervises. A superseded loop no longer says a person resumes it: it says, as `status` does, that resume is refused, and names the successor when `status --json` carries one. An unmanaged loop's Pause no longer sends an undefined `managedId`. The setup form's goal note now says `--with-goal` needs v0.1.5 or later.
