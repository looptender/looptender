- `looptender panel` now opens a panel whose page can pause, stop and resume loops, each after its review and confirmation; `--read-only` opens one that cannot, and `--allow-changes` (still accepted) also offers build replacement, route and send-allowance edits, account sign-in and quota reads. Opening the panel in a stronger mode restarts a running weaker one, never running two. A panel that changes loops now opens only for the exact caller that started it, and keeps the supervised-loop marker, so a supervised conversation, or anything its supervisor started, still cannot resume its own loop from it. The macOS menu has one "Open looptender Panel" item.
