- BB plugin: after the install's `current` link moves to a new build, `bb plugin reload keepgoing` keeps serving the old bundle, because BB's server process keeps the modules it loaded from that path. The plugin can now be stamped with the looptender build it is built from (`node stamp-build.mjs <label>` in the staged copy before `bb plugin build`), which makes each build a distinct plugin version, and `bb looptender status` ends with a line saying which build the plugin was built from and whether that is the build it runs. The README and the upgrading notes say what to run after an install (`bb plugin install path:<build directory>/bb-plugin-keepgoing --yes`, or restart BB).
