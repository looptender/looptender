- Loops follow the current standing wake policy after an upgrade. A `prompt.md` whose text above `Task:` is exactly as some version of setup wrote it is now sent with the running build's wording followed by the file's own task; the file is not rewritten. A prompt file edited above `Task:` is sent exactly as written, and `status`, `doctor` and the new `prompt-policy show` say that it receives no policy updates; `prompt-policy apply` makes it follow the built-in policy again, keeping its task and the previous file. See [standing wake policy](docs/setup.md#standing-wake-policy).
