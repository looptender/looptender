- BB plugin: **Add to Looptender** on an existing thread now defaults to **Keep this conversation going**, which needs no typing. The task is fixed text telling the agent to continue the work already under way in this conversation, following the person's latest instructions and limits, to finish and verify it, mark the loop complete, and use await-user when it needs the person or finds no task to continue; the plugin reads nothing from the conversation. An optional one-line **Anything to add?** note is appended, and the preview shows the exact task. **Write my own task** remains the second choice. On a thread BB's metadata shows has not had a turn, the typed task is the default, with a line saying why. The setup RPC gains additive `mode`, `note`, and result `task` and `conversation` fields.
