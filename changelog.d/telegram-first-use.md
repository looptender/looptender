- `looptender telegram service install|status|uninstall` keeps the Telegram poller running (macOS launchd job in the per-user background domain, Linux systemd user unit); only a person installs it. `doctor` says whether a poller runs for a loop that reports to Telegram. `telegram setup` refuses to read a token typed at a terminal and prints a silent command instead; the token file is refused at every read when others can read it; an overriding `LOOPTENDER_TELEGRAM_BOT_TOKEN` is reported. From the phone, a stopped or finished loop takes a second, separately worded confirmation; Prepare resume is not offered for superseded, disabled or archived loops; the review says who set each hold and never sends its note; a stale `/status` after sleep gets a reply.
